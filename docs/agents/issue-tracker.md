# Issue tracker: Linear

Issues and specs live in Linear, team **ENG** (identifiers like `ENG-320`). GitHub Issues are not used.

Use the Linear MCP server for every operation. Its own instructions and tool descriptions are the source of truth for how to create, read, label, comment on and close issues. This file only records what is specific to this repo.

- **Design docs and decisions** go on the issue as a Linear document, not as files under `docs/`.
- **Branches** use the issue's suggested branch name (`eng-<n>-<slug>`), and the PR title names the issue identifier.
